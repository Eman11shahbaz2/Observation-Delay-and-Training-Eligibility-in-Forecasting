Dated 11 October 2026. Frozen before loading development targets for this run. This execution addendum finalizes NEXT_STUDY_DRAFT.md without changing its research question. - Execute settings in order (O,L)=(0,0),(0,24),(24,0),(24,24); datasets Bike then Beijing, periods T1 then T2; selector order chronological, earlier_validation, random_42 through random_46. Model tie order persistence, Ridge, RF, HGB.
- Eligibility is the draft's explicit intersection of finite exact targets and finite persistence at O=0 and O=24, applied to both historical and future origins. The pilot used O=0,6,24. Record any membership differences from that pilot mask; do not adapt eligibility based on scores. Covariates stay at t-1, as stipulated in the original feature ledger.
- Use chronological_split with delay O+L for label maturity only; build_features receives O only. The earlier-validation comparator sorts the exact chronological train/validation union, assigns the first n_validation origins to validation and the remainder to training. Random comparators preserve that union and counts using the original generator and seeds 42–46.
- The common scale is historical-label IQR over eligible origins before B with t+55<=B. No future-based normalization. All settings share the future mask; the primary pair shares every split and refit membership.
- Run all 384 fits if feasible, with no cache or borrowing of previous predictions. Three independent candidate fits may run concurrently in separate processes; each pipeline retains its original one-thread configuration and random state. Concurrency changes execution order, not inputs or model parameters.
- Save all seven choices, their inner scores, lock timestamp and the last completed inner-fit timestamp before submitting any common-history future fit in that setting. Save independent fit timestamps and completion accounting. Persistence has no fit ledger entry.
- Fail rather than silently skip on numerical or source-validation errors. Infeasible cases are recorded without revising boundaries. Zero IQR leaves normalized contrasts missing. Report all four dataset-period units and all five seed values, with descriptive within-unit mean/range and no pooled hypothesis tests.
- Store feature snapshots once per O because they are identical across L. Store maturity records per O,L, split membership and all predictions for every selector and candidate. Byte hashes freeze implementation and protocol before loading.
- Reserved numeric target rows are excluded by the unchanged guarded prefix loader. Full public archives contain those rows, so this is a procedural analysis reservation rather than a confidential access boundary. Date-only metadata reads are permitted; no reserved future windows are scored.

Run with `python3 run_full_experiment.py --workers 3`. Before fitting, run the inherited and extended synthetic checks. After fitting, independently reconstruct metrics, choices, contrasts, timing and membership from saved outputs.
